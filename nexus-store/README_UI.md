# Nexus Store UI

Navigation publique :

- `index.html` — accueil
- `search.html` — recherche
- `categories.html` — catégories
- `library.html` — bibliothèque
- `app.html?id=<id>` — fiche dédiée de chaque application
- `account.html` — Compte Nexus
- `settings.html` — paramètres

Les fiches utilisent le catalogue central `catalog.json`. Chaque application possède une URL distincte déterminée par son identifiant de catalogue.
