# Compatibilité

Nexus Store Web/PWA utilise des pages statiques, un manifeste Web App et un service worker. Les installations Android continuent d'utiliser les URL APK du catalogue et l'installateur système. Sur iPhone/iPad, la version web peut être ajoutée à l'écran d'accueil ; les applications iOS natives doivent être distribuées et signées séparément selon les mécanismes Apple autorisés.
