Installation sur iPhone / iPad

Une application Android (.apk) ne peut pas être installée sur iOS. Nexus Store peut cependant fonctionner comme application web ajoutée à l’écran d’accueil. Les versions iOS natives apparaîtront ici lorsqu’elles seront signées et distribuées par une méthode Apple autorisée.

  1. Ouvre cette page dans Safari.
  2. Touche le bouton Partager.
  3. Choisis « Ajouter à l’écran d’accueil ».
