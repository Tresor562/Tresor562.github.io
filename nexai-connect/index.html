Comment ça marche

Numéro, code Telegram, puis 2FA uniquement si elle est activée.

01
Entrer le numéro

NexAccount demande à Telegram d'envoyer un code de connexion au compte.

02
Vérifier le compte

Saisissez le code Telegram. Si la 2FA est active, NexAI demandera ensuite le mot de passe.

03
Session connectée

La session NexAccount est créée et apparaît dans Telegram → Appareils connectés.
